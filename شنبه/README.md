# بات فاکتور باربری حداد کالا

این پروژه اطلاعات فاکتور را مرحله‌به‌مرحله دریافت می‌کند، خلاصه را برای تأیید نشان می‌دهد و پس از تأیید PDF می‌سازد. دسترسی به بات به `ALLOWED_USER_IDS` محدود است.

## سربرگ و فاکتور

فاکتور PDF به اندازهٔ استاندارد A5 ساخته می‌شود و تاریخ و ساعت تهران را در بالای صفحه نشان می‌دهد. پلاک را به شکل چهار بخش وارد کنید؛ برای نمونه `۷۶ ص ۳۸۱ - ۶۰` (دو رقم، حرف، سه رقم و کد دو رقمی). بات تا پنج ردیف محصول را جداگانه می‌گیرد و پیش از مبالغ، امکان افزودن ردیف بعدی یا پایان ثبت را می‌دهد. برای هر ردیف، نوع محصول، بسته‌بندی، مقدار و توضیحات کوتاه محصول ثبت می‌شود. توضیحات کلی در بخش پایین، کنار مبلغ و اطلاعات واریز قرار می‌گیرد. پس از اطلاعات بار، مبلغ حمل‌ونقل و هزینهٔ باربری را جداگانه و به تومان وارد کنید؛ جمع کل خودکار محاسبه می‌شود و هزینهٔ باربری می‌تواند صفر باشد.

تصویر پیوست‌شده در `assets/header.png` پایین فاکتور قرار می‌گیرد و نام شرکت، تلفن‌ها و امضای دست‌نویس/نام صاحب امضا را نشان می‌دهد. در پایان فرم می‌توان شمارهٔ پیش‌فرض خودکار را پذیرفت (با ارسال «خودکار») یا شمارهٔ دلخواه وارد کرد؛ شماره‌های استفاده‌شده در `data/invoice-numbers.json` نگه‌داری و تکراری بودن بررسی می‌شوند. شماره‌های خودکار با پیشوند `INVOICE_PREFIX` ساخته می‌شوند و شمارنده در `data/invoice-counter.json` نگه‌داری می‌شود. مقدار پیش‌فرض شروع ۱۰۰۰ است؛ بنابراین اولین شماره `HK-001001` خواهد بود. برای تغییر قالب شماره، `INVOICE_PREFIX` و برای تعیین نقطه شروع `INVOICE_START` را در `.env` تغییر دهید. فایل‌های شماره‌گذاری را حذف یا عقب نبرید تا شماره تکراری صادر نشود.

در ویندوز از فونت Arial سیستم استفاده می‌شود. روی لینوکس، برنامه ابتدا فونت Noto Naskh Arabic یا DejaVu Sans سیستم و سپس `fonts/Vazirmatn-Regular.ttf` را پیدا می‌کند. اگر هیچ‌کدام نصب نباشند، هنگام شروع خطای واضح می‌دهد؛ روی سرور لینوکس یک فونت فارسی/عربی با پشتیبانی از حروف فارسی نصب کنید یا فایل فونت مجاز برای استفاده را داخل پوشه `fonts` قرار دهید.

کد ملی، شماره تماس و طول ورودی‌ها بررسی اولیه می‌شوند؛ بقیه داده‌ها در حافظه نشست کاربرند و پس از ارسال PDF پاک می‌شوند. PDF حاوی اطلاعات هویتی و بانکی است؛ فقط شناسه‌های تلگرامی مورداعتماد را در فهرست مجاز قرار دهید.

## آماده‌سازی ویندوز

1. Python 3.10 یا جدیدتر نصب کنید و این پوشه را استخراج کنید.
2. `.env.example` را به `.env` تغییر نام دهید. توکن BotFather، شناسه عددی تلگرام خودتان، شماره کارت یا شبای متعلق به خودتان و نام صاحب حساب را فقط در `.env` وارد کنید. توکن را در چت یا کد قرار ندهید.
3. شناسه عددی تلگرام را از منبع مورد اعتماد خودتان بگیرید؛ فقط شناسه‌های مجاز را در `ALLOWED_USER_IDS` بگذارید. چند شناسه را با کاما جدا کنید.
4. ویندوز معمولاً فونت Arial را خودش دارد و نیازی به فایل اضافه نیست. اگر فونت پیدا نشد، یک فونت مجاز فارسی/عربی در `fonts/Vazirmatn-Regular.ttf` بگذارید یا `FONT_REGULAR` را در `.env` روی مسیر فونت تنظیم کنید.
5. PowerShell را در همین پوشه باز کنید و اجرا کنید:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python bot.py
```

اگر PowerShell اجازه فعال‌سازی نداد، در همان پنجره می‌توانید به‌جای فعال‌سازی این دستور را برای نصب استفاده کنید: `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` و سپس اجرا: `.\.venv\Scripts\python.exe bot.py`.

در تلگرام `/start` یا `/new` بفرستید، مراحل را کامل کنید، خلاصه را بررسی و تأیید کنید. برای آزمایش، اطلاعات ساختگی استفاده کنید. بات با polling اجرا می‌شود و تا وقتی پنجره ترمینال باز است کار می‌کند؛ `Ctrl+C` آن را متوقف می‌کند.

## اجرای ۲۴ ساعته

برای دسترس‌پذیری دائم به میزبانیِ دارای پردازش دائمی نیاز است. پروژه را روی VPS یا سرویس مناسب اجرا کنید، Python را نصب و وابستگی‌ها را نصب کنید، سپس متغیرهای `.env` را در بخش امن Environment Variables/Secrets سرویس تنظیم کنید. فایل فونت را نیز مستقر کنید. `python bot.py` را به‌عنوان سرویس با راه‌اندازی مجدد خودکار اجرا کنید. اگر بعدها ذخیره‌سازی فاکتورها اضافه شد، پوشه داده باید دیسک پایدار و پشتیبان‌گیری امن داشته باشد. این پروژه فعلاً PDF را فقط به کاربر درخواست‌کننده در تلگرام می‌فرستد و آرشیو دائمی ندارد.

## استقرار آزمایشی روی Render

پروژه فایل `render.yaml` و `Dockerfile` آماده دارد. برای استقرار، کل پروژه را در یک مخزن خصوصی GitHub قرار دهید؛ `.env`، `.venv`، گزارش‌ها و پوشه `data` را بارگذاری نکنید. سپس در Render یک Blueprint بسازید و همان مخزن را انتخاب کنید. Render وابستگی‌ها و فونت فارسی Noto را از داخل Dockerfile نصب می‌کند و برنامه را با webhook اجرا می‌کند.

هنگام ساخت سرویس، این مقادیر محرمانه را در بخش Environment وارد کنید: `BOT_TOKEN`، `ALLOWED_USER_IDS`، `CARD_NUMBER`، `ACCOUNT_HOLDER` و `WEBHOOK_SECRET`. برای `WEBHOOK_SECRET` یک مقدار تصادفی طولانی بسازید که فقط حروف انگلیسی، رقم، خط زیر یا خط تیره داشته باشد. توکن را داخل مخزن یا کد نگذارید. شماره شروع و پیشوند فاکتور هم از `INVOICE_START` و `INVOICE_PREFIX` قابل تنظیم‌اند.

پلن رایگان Render برای آزمایش است: ممکن است سرویس بعد از بی‌کاری خاموش شود و با اولین درخواست دوباره بالا بیاید. شمارنده و فهرست شماره‌های صادرشده روی دیسک موقت این پلن ذخیره می‌شوند و با راه‌اندازی مجدد ممکن است از نو شروع شوند؛ برای فاکتور واقعی از پلن رایگان استفاده نکنید. اطلاعات آزمایشی ساختگی وارد کنید.
